Courriel OAuth

Choisissez le fournisseur de votre boîte courriel, puis suivez les étapes ci-dessous pour obtenir un Client ID (et un Client Secret pour Google) - une inscription unique à faire dans la console de ce fournisseur, hors de SwitchBoard.

Microsoft 365 : comment obtenir un Client ID
  1. Allez sur portal.azure.com → Inscriptions d'applications → Nouvelle inscription.
  2. Donnez-lui un nom (ex.: « SwitchBoard Mail »), laissez le reste par défaut, puis Enregistrer.
  3. Copiez l'« ID d'application (client) » affiché - c'est le Client ID à coller ci-dessous. Copiez aussi le « ID de l'annuaire (locataire) » (Tenant ID) affiché juste à côté sur cette même page - avec les réglages par défaut (« Comptes dans cet annuaire organisationnel uniquement »), ce Tenant ID est OBLIGATOIRE ci-dessous, PAS optionnel (voir la note Tenant plus bas - le laisser vide cause l'erreur AADSTS50059).
  4. Authentification → Paramètres avancés → « Autoriser les flux clients publics » → Oui → Enregistrer.
  5. Rien à faire dans « Autorisations API » pour ce flux : SwitchBoard demande directement la permission SMTP.Send au moment de l'autorisation ci-dessous (c'est Microsoft qui affiche alors l'écran de consentement) - vous n'avez pas besoin de la chercher/ajouter vous-même dans le portail. Si votre tenant exige un consentement admin, l'écran de consentement vous le dira à ce moment-là plutôt qu'ici.
  6. Étape séparée obligatoire : un administrateur Exchange doit aussi activer l'authentification SMTP sur la boîte courriel elle-même (désactivée par défaut). Voir MAIL-OAUTH-SETUP.md pour la commande exacte - sans cette étape, l'envoi échouera même une fois autorisé ici.
  7. Tenant : avec les réglages d'inscription par défaut (mono-tenant), ce champ est OBLIGATOIRE - collez l'ID de l'annuaire (locataire) copié à l'étape 3 (ou le nom de domaine de votre organisation, ex.: contoso.onmicrosoft.com). Le laisser vide envoie la demande à l'adresse générique « common », que Microsoft refuse pour une inscription mono-tenant avec l'erreur AADSTS50059 « No tenant-identifying information found ».
Google : comment obtenir un Client ID et un Client Secret
  1. Allez sur console.cloud.google.com → Identifiants (créez un projet si vous n'en avez pas).
  2. Écran de consentement OAuth : type Externe, remplissez le nom de l'app et un courriel de support, Enregistrer (le mode « Test » suffit - ajoutez votre propre adresse comme utilisateur de test).
  3. Identifiants → Créer des identifiants → ID client OAuth → type d'application « Application Web ».
  4. Dans « URI de redirection autorisés », collez EXACTEMENT cette adresse :

    https://127.0.0.1/SwitchBoard/SwitchBoard/src/managementportal.php?page=mailoauth

  5. Créez, puis copiez le Client ID ET le Client Secret affichés - collez-les ci-dessous.
