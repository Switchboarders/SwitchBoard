Surveillance (dead-man's-switch)

Chaque ligne ci-dessous correspond à une chose critique à surveiller. Créez un compte gratuit sur un service de type dead-man's-switch (ex.: healthchecks.io), créez-y un check par ligne, collez son URL de ping ici, puis envoyez un ping de test. Le canal de notification (SMS, Telegram, ntfy, etc.) se configure entièrement chez ce fournisseur, pas ici - voir DEADMANSWITCH-SETUP.md pour le guide complet.

Groupes de sonnerie (refreshallringgroups.php, à toutes les 10 min)

Configuré.

Géré par une variable d'environnement (SB_DMS_RINGGROUP_SUCCESS_URL dans .env) - pour changer, modifiez .env puis redémarrez le conteneur.
